## Codebase Patterns
- Use `const` and `let` (never `var`); arrow functions; async/await
- New modules go in `app/<moduleName>/index.js` following single-responsibility principle
- Private class fields use `#property` syntax
- Run `npm run lint` before committing; ESLint config is in project root
- IPC channels must be added to allowlist in `app/security/ipcValidator.js`
- `createMainWindow()` in `app/mainAppWindow/index.js` is the window factory (exported). `onAppReady` initialises module-level state (config, iconChooser, etc.) then calls `createMainWindow()`. Call `createMainWindow()` to recreate the window after closure.
- `windowManager` singleton lives at `app/windowManager/index.js` — require it with `require('../windowManager')` (from mainAppWindow) or `require('./windowManager')` (from app/index.js)
- Tray icon active = `config.trayIconEnabled` is truthy; used to decide whether to keep process alive after all windows close
- To override Electron's default quit-on-all-windows-closed, add `app.on('window-all-closed', () => {})` and handle quit via `windowManager.on('all-closed', ...)`
- Avoid circular deps: `mainAppWindow → menus → tray`. Pass factory callbacks as constructor params rather than requiring mainAppWindow from menus/tray.
- `Menus` constructor signature: `(window, configGroup, iconPath, connectionManager, createMainWindow)` — the 5th param is optional and enables tray/open to recreate the window.
